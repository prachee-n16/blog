Notation: $r \cap s$  
Mathematical Definition: $r \cap s = \{t | t \in r \text{ and } t\in s\}$ 
- r and s have the same arity i.e. same number of attributes
- The domain names for r and s must be compatible i.e. the types of values allowed for an attribute are the same

Note: $r \cap s = r - (r - s)$
