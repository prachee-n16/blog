Notation: $\sigma_p(r)$ 
- $p$ is the selection predicate which defines the condition used to filter tuples in a relation.

Mathematical Definition: $\sigma_p(r) = \{t | t \in r \text{ and } p(t)\}$ 
- p is a formula in propositional logic with **terms** connected by $\land, \lor, \lnot$   
- Terms look like: `<attribute> op <attribute> or <constant>` where `op` is a comparison operator
